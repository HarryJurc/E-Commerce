# Проект E-Commerce

Этот проект реализует функциональность интернет-магазина.

## Классы:
- **Product**: Описание товара с атрибутами (название, описание, цена, количество).
- **Smartphone**: Наследуется от Product. Дополнительно содержит характеристики: модель, производительность, объем встроенной памяти, цвет.
- **LawnGrass**: Наследуется от Product. Дополнительно содержит характеристики: страна-производитель, срок прорастания, цвет.
- **Category**: Категория товаров с возможностью добавления продуктов. Подсчитывает количество товаров в категории и системе.

### Функциональность:
- Создание и добавление продуктов в категории.
- Автоматическое обновление счетчиков категорий и продуктов.
- Ограничение сложения товаров: теперь складывать можно только товары одного типа.
- Защищенный метод добавления продуктов в категории: теперь можно добавлять только объекты Product или его наследников.

Проект предоставляет базовую модель для учета товаров и категорий.

## Требования:
- Python 3.x
- pytest (для запуска тестов)
